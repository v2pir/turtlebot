automation.py v1 — Simple

Opens 4 terminals with a fixed 10-second delay between each. Simple but fragile — if a step takes longer than 10s, the next step starts too early.

automation2.py v2 — Smart

Watches each terminal's log output in real-time for a specific regex pattern, then launches the next step. Robust — adapts to however long each step actually takes.

How the brain works

Four interlocking mechanisms from cuttlefish_model.py

MECHANISM 01

Episodic Memory

A 3D array [what × when × where] that stores learned values. Updated using a delta rule: V += lr × (reward - V). The robot remembers what worked and where.

MECHANISM 02

Softmax Choice

Boltzmann action selection — converts memory values into probabilities. Higher-valued options are chosen more often, but there's always a chance of exploring the other option.

MECHANISM 03

Patience Model

A sigmoid function modulated by a "serotonin-like" signal. Low hunger = patient (willing to wait). High hunger = impulsive (takes the quick option). Controlled by BETA = 8.0.

MECHANISM 04

Hunger Dynamics

Hunger rises each trial without food (+0.05), drops when eating (-0.2). Creates a feedback loop: starving → impulsive → takes dead shrimp → partially fed → slightly more patient.

brain.py — Robot State Machine

The e-puck robot in Webots follows this state machine each trial. It uses its camera to detect chamber colors and GPS to know when it crosses thresholds.

idle — 3-second pause. Pre-trial period before the robot "perceives" both chambers.
choose — Softmax over episodic memory values. Picks blue (immediate) or red (delayed).
turn → approach — Uses camera color detection to steer toward chosen chamber, then drives forward until GPS says it crossed the threshold line.
